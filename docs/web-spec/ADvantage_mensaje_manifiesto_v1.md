## Copy final

**Headline:**
> ¿Por qué existe ADVANTAGE?

**Body:**
> No elegimos entre ser creativos o analíticos. Esa es precisamente la ventaja.
>
> La mayoría de las agencias te vende intuición disfrazada de estrategia. Toman decisiones basadas en lo que funcionó para otro cliente, en otro momento, con otro presupuesto.
>
> Nosotros operamos distinto. Cada servicio que ofrecemos corre sobre un sistema de workflows documentados — auditables, mejorables, sin cajas negras. No dependes de que una persona tenga un buen día. El sistema siempre entrega.
>
> Pero un sistema sin alma produce contenido que no conecta, anuncios que se ignoran, y páginas que nadie recuerda. Por eso combinamos rigor técnico con visión creativa. No como un compromiso entre dos fuerzas opuestas — como la única forma de hacer marketing que funciona.
>
> Eso es ADVANTAGE.

**Principios de la agencia:**
1. El sistema es el producto. No lo que hacemos, sino cómo lo hacemos.
2. Cada falla hace el sistema más fuerte. Documentamos, aprendemos, actualizamos.
3. Sin datos no hay opinión. Pero los datos sin narrativa son ruido.
4. Los entregables viven en la nube del cliente. Nunca en carpetas que nadie puede auditar.
5. La transparencia no es un valor — es el modelo. El cliente puede ver cada workflow.

## Nota de layout para Code

Esta página usa el modo **Contraste Cream** (`#F5EEE3` fondo, texto Void), no el modo principal Void — el manual ya define este fondo para "bandas editoriales · citas", y el manifiesto es exactamente ese caso de uso. No lo construyas con el fondo oscuro del resto del sitio.

- Headline en H2 (Fraunces 500, 36px, -2%).
- Body en tamaño ligeramente mayor al estándar (es texto para leer con calma, no un párrafo de conversión) — considerar 18-19px con 170% line-height, dentro del rango BODY del manual.
- Principios como lista numerada, JetBrains Mono para el número (consistente con el uso de mono en labels/counters del resto del sitio), Inter para el texto del principio.
- Motion: ScrollReveal simple por párrafo, sin CountUp (no hay números que animar aquí) y sin el glow parallax del hero (esta página es de lectura, no de aterrizaje).
