# Fórmulas de Copywriting Persuasivo

Las fórmulas no son plantillas arbitrarias: **mapean los procesos naturales de toma de decisiones del cerebro**. La selección depende enteramente del **nivel de conciencia del consumidor** (Eugene Schwartz). Elegir mal la fórmula = hablarle a la audiencia en la etapa equivocada.

## Paso 1 — Diagnosticar el nivel de conciencia

| Nivel (Schwartz) | Estado del prospecto |
|---|---|
| **Oblivious / Unaware** | No sabe que tiene un problema |
| **Problem-Aware (Hurting)** | Siente el dolor, no conoce soluciones |
| **Solution-Aware** | Sabe que existen soluciones, no conoce tu producto |
| **Product-Aware** | Conoce tu producto, duda si es para él |
| **Most Aware** | Solo necesita la oferta/empujón final |

## Paso 2 — Elegir la fórmula

| Fórmula | Desglose estructural | Nivel de conciencia y aplicación óptima |
|---|---|---|
| **PAS** (Problem, Agitation, Solution) | **P**: identificación validada del dolor. **A**: intensificación emocional de las consecuencias. **S**: el producto como alivio analgésico. | **Problem-Aware.** Ideal para Reels, TikToks y anuncios de respuesta directa. Apela a la aversión a la pérdida. |
| **AIDA** (Attention, Interest, Desire, Action) | **A**: ruptura del patrón de navegación. **I**: retención mediante empatía o datos. **D**: transición al beneficio emocional. **A**: instrucción directiva de cierre. | **Bajo nivel de conciencia.** Videos introductorios, narrativa de marca (TOFU), landing pages. |
| **BAB** (Before, After, Bridge) | **B**: situación deficiente actual. **A**: visualización utópica de la resolución. **Bridge**: el producto como vehículo de transición. | **Solution-Aware.** Testimonios, casos de estudio, carruseles demostrativos. |
| **4 Ps** (Promise, Picture, Prove, Push) | **Promise**: declaración de cambio vital. **Picture**: pintura mental detallada del resultado. **Prove**: evidencia empírica y prueba social. **Push**: impulso a la conversión. | **Most Aware / high ticket.** Formatos largos y Social Ads de productos de alto valor. |
| **FAB** (Features, Advantages, Benefits) | **F**: especificaciones técnicas. **A**: función operativa de cada característica. **B**: impacto emocional y práctico en la vida del usuario. | **Product-Aware.** Reseñas, unboxings, lanzamientos tecnológicos. |
| **SCQA** (Situation, Complication, Question, Answer) | **S**: contexto inicial. **C**: desafío o elemento disruptivo. **Q**: planteamiento lógico de la duda. **A**: resolución metodológica. | **Educativo B2B.** Publicaciones extensas en LinkedIn, videos corporativos. |

## Paso 3 — Aplicar la ley del contraste

Toda fórmula debe orquestar una **disonancia entre la realidad actual del lector y un estado futuro deseable**, posicionando el mensaje como el único puente lógico. Si el texto solo expone hechos, no persuade.

## Procedimiento

1. Preguntar/inferir: producto u oferta, audiencia, nivel de conciencia, formato de destino, CTA.
2. Elegir la fórmula con la tabla (justificar la elección en una línea).
3. Redactar sección por sección, etiquetando cada parte (P/A/S, etc.) para que sea auditable.
4. Verificar contraste antes/después y un solo CTA.
5. Si el destino es video → pasar el resultado a `guion-video-corto` o `guion-dos-columnas`; si es carrusel/hilo/LinkedIn → al skill de formato correspondiente.

## Formato de salida

```
OFERTA: … | AUDIENCIA: … | NIVEL DE CONCIENCIA: … 
FÓRMULA ELEGIDA: … — porque …

[P] …
[A] …
[S] … + CTA: …

CONTRASTE: antes = … / después = …
```
