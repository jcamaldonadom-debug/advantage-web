# Hilo (Thread) para X

Los hilos superan el límite de caracteres para desarrollar narrativas o tutoriales complejos. El éxito depende **desproporcionadamente del primer tweet** (mega-gancho) y de la fragmentación cognitiva: una idea por tweet, flujo lógico, mapa de progreso.

## Estructura

### Tweet 1 — Mega-gancho
Debe responder de inmediato tres cosas:
1. **De qué** trata la serie.
2. **Para quién** es relevante.
3. **Qué beneficio tangible** se obtiene al llegar al final.

Usar `ganchos` para variantes (cifra, contraintuitivo, exclusividad). Anunciar la extensión ("Abro hilo 🧵" o "1/10") para fijar la expectativa y abrir el bucle.

### Tweets 2 a N-1 — Desarrollo
- **Numeración clara (2/10, 3/10…)** → mapa de progreso para el lector.
- **Una idea única por tweet**, autocontenida pero fluyendo lógicamente hacia la siguiente.
- Frases cortas, espaciado generoso, sin bloques densos.
- Mantener micro-bucles: terminar tweets clave con tensión ("y aquí viene lo que nadie hace:").

### Tweet final — Cierre
- **Resumen ejecutivo (TL;DR)** con los puntos clave en formato lista.
- **CTA de interacción**: pedir RT/repost del primer tweet, seguir la cuenta, o responder con una pregunta. Un CTA principal.
- Opcional: enlace al contenido largo (modelo puente — ver `estratega-contenido`).

## Reglas de redacción

- Cada tweet debe poder entenderse si aparece aislado en el feed (los tweets intermedios también captan tráfico).
- La primera línea de cada tweet es un mini-gancho: nunca empezar con relleno.
- Datos concretos > adjetivos ("+68% de interacción" > "mucho mejor").
- Nota AEO/GEO: los hilos estructurados, precisos y accionables son los que los motores generativos extraen como fuente de autoridad.

## Procedimiento

1. Confirmar: tema, audiencia, número de tweets objetivo (7–12 típico), CTA.
2. Listar las N ideas (una por tweet) y ordenarlas en progresión lógica.
3. Escribir el mega-gancho (3 variantes, elegir la más fuerte).
4. Redactar cada tweet ≤280 caracteres, numerado.
5. Cerrar con TL;DR + CTA.

## Plantilla de salida

```
HILO: … | TWEETS: N | CTA: …

1/N (MEGA-GANCHO)
"… [qué + para quién + beneficio] 🧵"

2/N
"…una sola idea…"

…

N/N (CIERRE)
"TL;DR:
• …
• …
• …
Si te sirvió: RT al primer tweet y sígueme para …"
```
